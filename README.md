# AI Video Stars

整理自 [wenlong66 的 GitHub 星标](https://github.com/wenlong66?tab=stars)，按用途收录 AI 视频项目与配套工具。

## 短剧、漫剧与整片创作

- [HBAI-Ltd/Toonflow-app](https://github.com/HBAI-Ltd/Toonflow-app)：AI 短剧与漫剧工作台，串联剧本、角色场景、分镜预演和视频生成。
- [chatfire-AI/huobao-drama](https://github.com/chatfire-AI/huobao-drama)：从小说或剧本生成角色、场景与分镜视频，并拼接导出完整短剧。
- [yi1108/printfilm](https://github.com/yi1108/printfilm)：分步制作 AI 漫剧与短视频，支持图生视频和静图配音成片。
- [modelscope/ms-agent](https://github.com/modelscope/ms-agent)：内含 Singularity Cinema 子项目，可从文本制作脚本、分镜和讲解短视频。

## Agent 视频制作与剪辑

- [OpenMontageInc/OpenMontage](https://github.com/OpenMontageInc/OpenMontage)：由编程 Agent 串联脚本、素材、剪辑、配音字幕与最终视频合成。
- [browser-use/video-use](https://github.com/browser-use/video-use)：让编程 Agent 剪辑已有素材，处理停顿、口头填充词、调色与字幕。
- [hypit-ai/hypit](https://github.com/hypit-ai/hypit)：从参考视频或文字创建可编辑工作流，组合镜头、字幕和特效并制作变体。

## 代码动画与可编辑视频

- [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)：让人和 AI Agent 用网页技术制作可编辑动效，并渲染为 MP4 视频。
- [zhongerxin/Cowart](https://github.com/zhongerxin/Cowart)：面向 Codex 的无限画布插件，可生成、编辑与导出 HTML/JS 动效影片。

## 视频理解与镜头拆解

- [OpenBMB/MiniCPM-V](https://github.com/OpenBMB/MiniCPM-V)：支持视频内容理解的多模态模型系列，包含连续音视频交互能力。
- [JuneYaooo/rea-video](https://github.com/JuneYaooo/rea-video)：拆解视频镜头、字幕、剪辑与音轨，输出分析报告及视频重制计划。

## 视频增强与后处理

- [Baiyuetribe/paper2gui](https://github.com/Baiyuetribe/paper2gui)：AI 桌面工具箱，提供视频超分、补帧、抠像和字幕相关工具。

## 配套工具

### 综合创作工作台

- [nexu-io/open-design](https://github.com/nexu-io/open-design)：综合 AI 设计工作台，集成视频生成与 HyperFrames 动效制作流程。

### 视频合成与渲染

- [remotion-dev/remotion](https://github.com/remotion-dev/remotion)：以 React 编写、预览和批量渲染视频，可作为 AI 视频工作流的合成基础。
- [FFmpeg/FFmpeg](https://github.com/FFmpeg/FFmpeg)：通用音视频处理工具，为 AI 视频提供转码、滤镜、字幕与最终合成。

### 配音与音乐生成

- [debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio)：本地 AI 语音工作台，支持视频翻译配音、声音克隆、声音设计和转写。
- [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM)：多语言文本转语音模型，支持声音设计与克隆，可制作旁白和角色配音。
- [multimodal-art-projection/YuE](https://github.com/multimodal-art-projection/YuE)：歌曲与音乐生成工具，支持歌词驱动、音乐编辑与翻唱，可制作视频配乐。

### 动作捕捉与动画素材

- [freemocap/freemocap](https://github.com/freemocap/freemocap)：动作捕捉系统，采集人物动作数据，为角色动画和视频制作提供素材。
- [0x0funky/agent-sprite-forge](https://github.com/0x0funky/agent-sprite-forge)：通过生成动作视频并抠像、抽帧和重定时，制作游戏精灵与循环动画素材。
- [aldegad/sprite-gen](https://github.com/aldegad/sprite-gen)：含图生动作视频、抽帧与循环裁切流程，可导出透明 GIF 和条带动画。

### 剧本与分镜

- [Narcooo/inkos](https://github.com/Narcooo/inkos)：故事创作 Agent，包含剧本与分镜技能，可用于 AI 短剧前期内容制作。
